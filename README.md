# Ритм — трекер привычек

Приложение для привычек на русском языке с установкой на домашний экран iPhone. React 19, TypeScript и Vite; шрифты включены в сборку, внешние сервисы и ключи для работы самого приложения не нужны.

## На iPhone

Node.js на телефоне не нужен. После публикации приложения на HTTPS-хостинге:

1. Откройте опубликованную ссылку в Safari.
2. Нажмите «Поделиться» → «На экран „Домой“».
3. Если доступен переключатель «Открывать как веб-приложение», оставьте его включённым и нажмите «Добавить».
4. Откройте Ритм с новой иконки и дождитесь первой загрузки с интернетом. Затем приложение доступно офлайн.

Подсказка по установке есть в настройках приложения. Оно открывается в отдельном окне, учитывает вырез экрана и нижний индикатор iPhone. Новые версии предлагаются через уведомление «Обновить»; незавершённая форма не прерывается автоматической перезагрузкой.

Safari и установленное приложение могут использовать отдельные хранилища. Для переноса уже введённых привычек используйте экспорт и импорт в настройках. Резервную копию стоит сохранить перед удалением приложения или очисткой данных Safari.

## Публикация

Приложению нужен статический HTTPS-хостинг. Публикация облачной среды разработки сама по себе не создаёт публичный сайт.

Для GitHub Pages подготовлен `.github/workflows/deploy-pages.yml`:

1. Разместите исходники в подключённом репозитории GitHub.
2. В его **Settings → Pages → Build and deployment** выберите **GitHub Actions**.
3. В **Actions → Publish Ritm to GitHub Pages** нажмите **Run workflow**.
4. После успешного выполнения адрес появится в результате deployment и разделе Pages.

Workflow запускается только вручную: отправка исходников не публикует сайт автоматически. Доступность Pages зависит от настроек и тарифа репозитория; менять его видимость для публикации без отдельного решения владельца не нужно. Путь проекта автоматически учитывается при сборке, и офлайн-режим работает как в корне сайта, так и в `/new/`.

Для другого статического хостинга загрузите содержимое `dist/` после обычной сборки. В архиве готовой сборки `index.html` должен находиться в корне. Не используйте `file://` для установки приложения: service worker требует HTTPS (исключение — локальная разработка).

## Запуск для разработки

Нужен Node.js 22.6 или новее; рекомендуемая версия — 24 (см. `.nvmrc`).

```bash
cd /workspace/new
npm ci
npm run dev
```

Dev-сервер использует порт 5173. `npm run dev -- --port 3000` позволяет выбрать другой порт. Для production-сборки:

```bash
npm run build
npm run preview
```

Содержимое `dist/` можно разместить на статическом хостинге. Для навигации используются URL-фрагменты, поэтому перенаправление всех запросов на `index.html` не требуется. В облачных задачах используйте существующий каталог `/workspace/new`: отдельный Git worktree не нужен.

## Возможности

- Список привычек с недельными отметками и видом «Сегодня», поиск и фильтр по категории.
- Создание, редактирование и удаление привычек; значки, цвета и расписание по дням недели.
- Календарь каждой привычки, переход к дате и добавление/отмена отметок за любой выбранный день.
- Количество выполнений, текущая и лучшая серии, регулярность за 30 дней и статистика месяца.
- Общая статистика, график по дням, сравнение привычек и карта активности.
- Светлая, тёмная и системная темы; выбор начала недели.
- Экспорт и импорт JSON с проверкой формата и подтверждением замены данных.
- Адаптивный интерфейс и управление модальными окнами с клавиатуры.
- Установка на домашний экран iPhone, офлайн-режим и уведомление об обновлениях.

Первый запуск показывает явно обозначенный пример из пяти привычек. «Начать с чистого листа» удаляет все текущие привычки и отметки после подтверждения, включая изменения, внесённые в пример.

## Данные и расчёты

Данные сохраняются в `localStorage` этого браузера под ключом `ritm.habits.v1`. Синхронизации между устройствами и аккаунтов нет; для переноса и резервной копии используйте экспорт в настройках. Очистка данных браузера удаляет локальные привычки. Ошибки сохранения отображаются пользователю.

Даты соответствуют локальному календарю устройства. Будущие отметки сохраняются, но попадают в статистику только после наступления даты. Отметки вне расписания учитываются в общем количестве, но не в сериях и регулярности. Невыполненный сегодняшний день не прерывает вчерашнюю серию до завершения дня. Отметка задним числом сдвигает начало отслеживания на эту дату; отмена отметки не сдвигает начало обратно.

## Проверка

```bash
npm test
npm run build
```

11 тестов проверяют календарные даты и переходы времени, серии, расписание, исторические и будущие отметки, агрегаты и импорт. Сборка включает строгую проверку TypeScript.

При разработке дополнительно проверены 14 пользовательских сценариев в Chromium на экранах 1440 и 390 px: создание, редактирование, исторические отметки, сохранение после перезагрузки, темы, экспорт/импорт, подтверждения удаления, навигация и фокус модальных окон.

Проверки установки и офлайн-режима:

```bash
npx playwright install chromium
npm run test:pwa
VITE_BASE_PATH=/new/ npm run test:pwa
```

На машине с системным Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium`. Тесты сами собирают production-версию и запускают сервер на порту 4175. В каждом режиме выполняются шесть проверок: манифест и иконки, работа и редактирование без сети с отключённым HTTP-кэшем, сохранение после перезагрузки и инструкция установки; проверяются обычный экран и размер iPhone. Проверка в Chromium с размером экрана iPhone не заменяет ручную установку в Safari на настоящем устройстве.
